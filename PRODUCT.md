# Product

## Platform

web

## Stack

React + Vite + TypeScript with Lucide icons. The first surface is a local, self-contained learning experience; the simulated command/query outputs are intentionally illustrative.

## Users

People starting from zero who want a durable mental model of Linux and SQL, plus developers who want a concise refresher before working in a terminal or database.

## Product Purpose

field/guide teaches Linux and SQL as connected systems rather than as lists of syntax. Each lesson moves from a plain-language idea to a diagram, then to a runnable-looking example and a deeper explanation.

## Positioning

A calm technical field guide: more visual and guided than reference documentation, more concept-first than a command quiz.

## Operating Context

Used in a desktop browser while studying, with occasional mobile access. A learner should be able to switch between Linux and SQL from the persistent sidebar, choose a lesson, run the local demonstration, and continue without losing context.

## Capabilities and Constraints

- Persistent Linux / SQL switcher in the sidebar.
- Beginner-first curriculum with deeper explanations, common pitfalls, and mental-model summaries.
- Illustrative filesystem and relational-schema diagrams.
- Local terminal and SQL query sandbox UI with synthetic output; it does not execute commands or connect to a real database.
- Responsive off-canvas sidebar and compact mobile lesson layout.
- Search filters the current learning path.

## Brand Commitments

- Product name: field/guide.
- The experience should feel modern, precise, welcoming, and technically serious without becoming intimidating.
- Explanations should teach why a command or clause exists, not only what to type.

## Product Principles

- Show the structure before asking for memorisation.
- Pair every idea with a visible result.
- Give beginners a safe next step and experts a deeper layer.
- Keep the active mode and lesson obvious at all times.
- Label synthetic examples honestly.

## Accessibility & Inclusion

Use semantic buttons and headings, visible keyboard focus, sufficient contrast, reduced-motion support, readable copy, and a responsive layout. The simulated lab is always accompanied by a plain-language explanation.
