# field/guide

Une app web responsive pour apprendre Linux et SQL de zéro : parcours guidés, schémas explicatifs, laboratoire terminal/SQL simulé et approfondissements.

## Lancer le projet

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:5173`.

## Stack

- React + Vite + TypeScript
- Lucide pour les icônes
- Démonstrations locales et synthétiques : aucun terminal ni serveur SQL réel n’est contacté

Les parcours Linux et SQL sont accessibles depuis la barre latérale. Chaque leçon alterne explication, illustration, pratique et piège courant.
